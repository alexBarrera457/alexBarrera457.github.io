EventSportsBCN

Sports event management platform for Barcelona

A full-stack web application for managing and discovering sports events across Barcelona. Built with a clean MVC architecture in PHP, it handles two distinct user roles with separate dashboards and permissions.

  • Role-based auth — regular users and event managers with different access levels
  • Event registration with real-time capacity tracking per event
  • Manager dashboard to create, edit and monitor registrations
  • Supports 5 sports: Basketball, Football, Golf, Tennis, Paddle
  • Relational MySQL database with 3-entity schema
  • Fully responsive custom frontend in HTML, CSS and vanilla JS
